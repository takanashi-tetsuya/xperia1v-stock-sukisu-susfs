A2 額外安排 root 專用早期核心日誌 observer，原廠組沒有同樣收集；唯讀收集仍可能增加觀察負載。補充收集是否成功不影響本報告的完成門檻；比較計數只取共同 crash 紀錄，不以 dmesg 未出現訊息推論沒有故障。

init 結論：原廠也記錄 init 命名程序 SIGABRT，因此自訂核心不是這一大類事件的必要條件；不能推論每個事件同因、無害、發生率相等，或 r3 額外事件與核心/root 組合無關。
IWLAN 結論：四輪 matched 的模組隔離 r3 / 原廠窗口都沒有 IWLAN NPE，但相同 r3 核心恢復原模組的第五輪有陽性重現（次數見表格與下列摘錄）。這是另一組條件的恢復觀察，不是第三個 matched r3 樣本；不能判定某個模組有問題或證明模組造成崩潰，啟動、電信商/modem 狀態及時序仍未控制。 後續替換服務有 provider、處理回應與更新活動，窗口末仍見相同服務/provider；啟動 backoff 日誌不足以證明一直停擺。這仍不是 IMS/VoWiFi 或通話功能驗證。

限制：每組只有兩次、同一支手機；無法比較發生率或宣稱頻率相等。手動解鎖、電信商/modem/SIM 狀態和背景排程未完全控制。原廠若重現只表示自訂核心不是這一大類事件的必要條件，不證明每個 abort 同因、無害或 r3 多出的事件與核心無關。兩組均未重現 IWLAN 時仍屬無陽性重現，不能排除核心或模組參與。
普通 adb bugreport 在比較窗口後取得，dumpstate 可取得部分 shell 無權直接讀取的 native 資料；完整 ZIP 僅留私人目錄。來源 SHA 與行號不能替代完整原始證據或保證沒有其他故障。未驗證通話、SMS、IMS、VoWiFi、漫遊、吞吐、OTA 或長期穩定。

A2 bugreport 是使用者中斷後、確認仍為同次開機才補收；前三輪則在窗口結束後不久取得。因此補充 bugreport 的時點不完全相同。比較計數仍採各輪已完成的共同 crash 收集（含保留的啟動事件），不以延遲補收來延長窗口或改算 matched 計數。
